# Spec Delta

## ADDED Requirements

### Requirement: Статуси «Частково схвалено» й «Повернено на доопрацювання» підписано текстом англійською
WHEN заявку зі статусом «Частково схвалено» чи «Повернено на доопрацювання» показано у списку, на сторінці заявки або в
історії, the system SHALL підписати статус текстом «Partially approved» чи «Returned for revision» відповідно, а не лише
кольором.

#### Scenario: AC-LANG-09 Нові статуси підписано англійським текстом
- **GIVEN** заявка зі статусом «Частково схвалено» чи «Повернено на доопрацювання»
- **WHEN** її показано у списку, на сторінці заявки або в історії
- **THEN** статус підписано текстом «Partially approved» чи «Returned for revision» відповідно
- **AND** статус не передано лише кольором
