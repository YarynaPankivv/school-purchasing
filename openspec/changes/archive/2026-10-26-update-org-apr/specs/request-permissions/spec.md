# Spec Delta

## ADDED Requirements

### Requirement: Дозволені типи заявок у профілі працівника
WHEN адміністратор відкриває профіль працівника, the system SHALL показувати серед дозволених йому типів заявок «Витрата
карткою», «Запит на чек» і «Рахунок постачальника» лише ті, на які працівнику без ролі `admin` видано дозвіл, а для
адміністратора — усі ці типи.

#### Scenario: AC-ORG-17 З дозволом «Витрата карткою» вона серед дозволених типів
- **GIVEN** працівник без ролі `admin`, якому адміністратор видав дозвіл на «Витрату карткою»
- **WHEN** адміністратор відкриває профіль цього працівника
- **THEN** серед дозволених йому типів заявок є «Витрата карткою»

#### Scenario: AC-ORG-25 Адміністратор без дозволу має «Витрату карткою» серед дозволених
- **GIVEN** адміністратор без дозволу на «Витрату карткою»
- **WHEN** адміністратор відкриває його профіль
- **THEN** серед дозволених йому типів заявок є «Витрата карткою»

#### Scenario: AC-ORG-26 Без дозволу «Витрати карткою» серед дозволених немає
- **GIVEN** працівник без ролі `admin` і без дозволу на «Витрату карткою»
- **WHEN** адміністратор відкриває профіль цього працівника
- **THEN** серед дозволених йому типів заявок «Витрати карткою» немає

### Requirement: Дозволені типи закупівлі в профілі працівника
WHERE працівник без ролі `admin` не має дозволу «Самостійна закупівля», the system SHALL показувати в його профілі серед
дозволених типів закупівлі лише «Відділ закупівель».

#### Scenario: AC-ORG-27 Без дозволу серед дозволених типів закупівлі лише «Відділ закупівель»
- **GIVEN** працівник без ролі `admin` і без дозволу «Самостійна закупівля»
- **WHEN** адміністратор відкриває профіль цього працівника
- **THEN** серед дозволених йому типів закупівлі є лише «Відділ закупівель»

## REMOVED Requirements

### Requirement: Типи заявок за дозволом
**Reason**: PM прибрала AC-ORG-07 із вимог (журнал змін ValiaBihun/2026-quitcode-dream-team#2, 2026-10-21) і повернула його
як AC-ORG-26 з результатом через профіль працівника; AC-ORG-17 переформульовано так само (вимога
ValiaBihun/2026-quitcode-dream-team#40); ID AC-ORG-07 повторно не використовується. Вимогу замінено новою «Дозволені типи
заявок у профілі працівника» (AC-ORG-17, 25, 26).
**Migration**: Поведінку «тип без дозволу не показується у виборі типу заявки» лишає код форми; тест з ID AC-ORG-07
перейменовуємо без ID (окремий коміт PR «Специфікація»), рядок AC-ORG-07 прибираємо з `docs/conformance.md`; AC-ORG-17, 25
і 26 — «відкладено (чекає реалізації)», доки профіль працівника не покаже дозволені типи.

### Requirement: Тип закупівлі без дозволу «Самостійна закупівля»
**Reason**: PM прибрала AC-ORG-08 із вимог (журнал змін ValiaBihun/2026-quitcode-dream-team#2, 2026-10-21) і повернула його
як AC-ORG-27 з результатом через профіль працівника (вимога ValiaBihun/2026-quitcode-dream-team#40); ID AC-ORG-08 повторно
не використовується. Вимогу замінено новою «Дозволені типи закупівлі в профілі працівника» (AC-ORG-27).
**Migration**: Поведінку «без дозволу лише „Відділ закупівель“ у виборі типу закупівлі» лишає код форми; тест з ID AC-ORG-08
перейменовуємо без ID (окремий коміт PR «Специфікація»), рядок AC-ORG-08 прибираємо з `docs/conformance.md`; AC-ORG-27 —
«відкладено (чекає реалізації)».
