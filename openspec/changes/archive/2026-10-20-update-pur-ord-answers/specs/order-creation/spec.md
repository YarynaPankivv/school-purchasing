# Spec Delta

## ADDED Requirements

### Requirement: Довідник постачальників
IF адміністратор додає в довідник постачальника з назвою, що без урахування регістру збігається з наявною, THEN the system
SHALL не додавати його й показати «Постачальник з такою назвою вже є».

#### Scenario: AC-ORD-36 Назва постачальника унікальна без урахування регістру
- **GIVEN** в довіднику постачальників є «Альфа»
- **WHEN** адміністратор додає постачальника «альфа»
- **THEN** його не додано
- **AND** адміністратор бачить «Постачальник з такою назвою вже є»
