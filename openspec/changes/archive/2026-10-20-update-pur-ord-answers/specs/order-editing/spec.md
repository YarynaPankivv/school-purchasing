# Spec Delta

## ADDED Requirements

### Requirement: Межі кількості й ціни рядка замовлення
IF адміністратор вводить у рядку замовлення кількість 0, нецілу кількість або від'ємну ціну, THEN the system SHALL не
приймати значення й назвати поле, а ціну 0 з цілою кількістю від 1 — приймати.

#### Scenario: AC-ORD-37 Нульова чи неціла кількість або від'ємна ціна не приймаються
- **GIVEN** рядок замовлення
- **WHEN** адміністратор вводить кількість 0, нецілу кількість або відʼємну ціну
- **THEN** значення не приймається
- **AND** повідомлення називає поле

#### Scenario: AC-ORD-38 Ціна 0 з цілою кількістю приймається
- **GIVEN** рядок замовлення
- **WHEN** адміністратор вводить ціну 0 і цілу кількість від 1
- **THEN** значення приймається

### Requirement: Статус закупівлі після видалення замовлень
WHEN адміністратор повністю видаляє замовлення закупівлі зі статусом «В обробці», the system SHALL лишити закупівлі
статус «В обробці», навіть якщо це було її останнє замовлення.

#### Scenario: AC-ORD-39 Після видалення останнього замовлення — «В обробці»
- **GIVEN** закупівля зі статусом «В обробці» з одним замовленням у статусі «Створено»
- **WHEN** адміністратор видаляє це замовлення повністю
- **THEN** закупівля лишається «В обробці»
