# Spec Delta

## ADDED Requirements

### Requirement: Режим «Детально»
WHERE замовлення має режим відправки «Детально», the system SHALL передавати в бухгалтерську систему по одному рядку на
кожен рядок замовлення.

#### Scenario: AC-ORD-35 «Детально» — по рядку на кожен рядок замовлення
- **GIVEN** замовлення в режимі «Детально» з двома рядками
- **WHEN** адміністратор відправляє
- **THEN** в бухгалтерську систему йдуть два рядки, по одному на кожен рядок замовлення
