# Spec Delta

## Purpose

Визначає чергу «Очікують обробки», з якої відділ закупівель бере схвалені закупівлі в роботу, доступ до неї й
архівування оброблених закупівель.

## ADDED Requirements

### Requirement: Склад черги «Очікують обробки»
WHEN адміністратор відкриває чергу «Очікують обробки», the system SHALL показувати в ній закупівлі зі статусами
«Схвалено», «Частково схвалено» чи «В обробці», що не в архіві, і не показувати закупівель інших статусів та архівних.

#### Scenario: AC-ORD-01 У черзі лише схвалені й оброблювані закупівлі поза архівом
- **GIVEN** адміністратор і закупівля зі статусами «Схвалено», «Частково схвалено» чи «В обробці», не в архіві
- **WHEN** він відкриває чергу «Очікують обробки»
- **THEN** закупівля там є
- **AND** закупівлі інших статусів і архівні там відсутні

### Requirement: Черга лише для адміністратора
IF користувач без ролі `admin` відкриває чергу обробки, THEN the system SHALL не надавати доступу й показати повідомлення
«Недостатньо прав».

#### Scenario: AC-ORD-27 Без ролі admin немає доступу до черги
- **GIVEN** користувач без ролі `admin`
- **WHEN** він відкриває чергу обробки
- **THEN** доступу немає, повідомлення «Недостатньо прав»

### Requirement: Архівування обробленої закупівлі
WHEN адміністратор архівує оброблену закупівлю, the system SHALL прибрати її з черги та лічильників, лишивши її в пошуку
й доступною для читання.

#### Scenario: AC-ORD-28 Архівна закупівля — поза чергою, але в пошуку
- **GIVEN** оброблена закупівля
- **WHEN** адміністратор її архівує
- **THEN** закупівля зникає з черги та лічильників
- **AND** вона лишається в пошуку і доступна для читання
