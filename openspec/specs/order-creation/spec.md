# order-creation Specification

## Purpose
Визначає, як відділ закупівель обирає постачальників для схвалених рядків закупівлі й створює з готових рядків по
замовленню на кожного постачальника.

## Requirements

### Requirement: Постачальник рядка
WHEN адміністратор обирає постачальника для схваленого рядка закупівлі, the system SHALL встановити рядку статус «Готовий
до замовлення», а після зняття постачальника — повернути рядку статус «Схвалено».

#### Scenario: AC-ORD-02 Вибір постачальника робить рядок готовим до замовлення
- **GIVEN** схвалений рядок закупівлі
- **WHEN** адміністратор обирає для нього постачальника
- **THEN** рядок має статус «Готовий до замовлення»
- **AND** зняття постачальника повертає рядок у «Схвалено»

### Requirement: Постачальник відхиленого чи замовленого рядка незмінний
IF рядок відхилено або вже включено в замовлення, THEN the system SHALL заблокувати зміну його постачальника.

#### Scenario: AC-ORD-03 Зміну постачальника заблоковано
- **GIVEN** відхилений рядок або рядок, уже включений у замовлення
- **WHEN** адміністратор намагається змінити його постачальника
- **THEN** зміну заблоковано

### Requirement: Замовлення лише з готових рядків
IF у закупівлі немає жодного рядка «Готовий до замовлення», THEN the system SHALL не створювати замовлення й показати
«Оберіть постачальника хоча б для одного рядка».

#### Scenario: AC-ORD-04 Без готових рядків замовлення не створено
- **GIVEN** закупівля без жодного готового рядка
- **WHEN** адміністратор намагається створити замовлення
- **THEN** замовлення не створено
- **AND** він бачить «Оберіть постачальника хоча б для одного рядка»

### Requirement: Замовлення на кожного постачальника
WHEN адміністратор створює замовлення, the system SHALL створити по одному замовленню на кожного постачальника готових
рядків, встановити цим рядкам статус «Замовлено», а закупівлі — «В обробці».

#### Scenario: AC-ORD-05 Два постачальники — два замовлення
- **GIVEN** готові рядки: два для постачальника А й один для постачальника Б
- **WHEN** адміністратор створює замовлення
- **THEN** з'являються два замовлення: А з двома рядками й Б з одним

#### Scenario: AC-ORD-29 Рядки замовлень мають статус «Замовлено»
- **GIVEN** готові рядки: два для постачальника А й один для постачальника Б
- **WHEN** адміністратор створює замовлення
- **THEN** ці три рядки мають статус «Замовлено»

#### Scenario: AC-ORD-30 Закупівля переходить у «В обробці»
- **GIVEN** готові рядки: два для постачальника А й один для постачальника Б
- **WHEN** адміністратор створює замовлення
- **THEN** закупівля має статус «В обробці»

### Requirement: Повторне створення замовлень
WHEN адміністратор знову створює замовлення для закупівлі «В обробці», the system SHALL створити нові замовлення лише для
рядків, готових на цей момент, не змінюючи наявних замовлень.

#### Scenario: AC-ORD-08 Нові замовлення лише для нових готових рядків
- **GIVEN** закупівля в «В обробці», де після першого замовлення з'явився новий готовий рядок
- **WHEN** адміністратор створює замовлення знову
- **THEN** нові замовлення створено лише для рядків, що були готові
- **AND** наявні замовлення не змінено
