# request-permissions Specification

## Purpose
Визначає, як дозволи, які адміністратор видає працівнику на типи заявок і на тип закупівлі «Самостійна закупівля»,
обмежують вибір типу заявки й типу закупівлі.

## Requirements

### Requirement: Типи заявок за дозволом
WHERE працівник з роллю `requester` або `approver` не має дозволу на тип заявки «Витрата карткою», «Запит на чек» чи
«Рахунок постачальника», the system SHALL не показувати цей тип у виборі типу заявки, а після видачі дозволу —
показувати його.

#### Scenario: AC-ORG-07 Без дозволу «Витрати карткою» немає у виборі
- **GIVEN** працівник без дозволу на «Витрату карткою»
- **WHEN** він відкриває вибір типу заявки
- **THEN** типу «Витрата карткою» там немає

#### Scenario: AC-ORG-17 З дозволом «Витрата карткою» є у виборі
- **GIVEN** працівник, якому адміністратор видав дозвіл на «Витрату карткою»
- **WHEN** він відкриває вибір типу заявки
- **THEN** тип «Витрата карткою» там є

### Requirement: Тип закупівлі без дозволу «Самостійна закупівля»
WHERE працівник не має дозволу «Самостійна закупівля», the system SHALL дозволяти йому обрати під час створення
закупівлі лише тип закупівлі «Відділ закупівель».

#### Scenario: AC-ORG-08 Без дозволу — лише «Відділ закупівель»
- **GIVEN** працівник без дозволу «Самостійна закупівля»
- **WHEN** він створює закупівлю
- **THEN** він може обрати лише тип закупівлі «Відділ закупівель»
