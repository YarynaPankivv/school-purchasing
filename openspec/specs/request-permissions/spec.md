# request-permissions Specification

## Purpose
Визначає, як дозволи, які адміністратор видає працівнику на типи заявок і на тип закупівлі «Самостійна закупівля»,
обмежують вибір типу заявки й типу закупівлі.

## Requirements

### Requirement: Адміністратор обирає будь-який тип закупівлі
WHERE користувач має роль `admin`, the system SHALL дозволяти йому під час створення закупівлі обрати будь-який тип
закупівлі, зокрема «Самостійна закупівля», без окремого дозволу.

#### Scenario: AC-ORG-23 Адміністратор без дозволу обирає «Самостійну закупівлю»
- **GIVEN** адміністратор без дозволу «Самостійна закупівля»
- **WHEN** він створює закупівлю
- **THEN** він може обрати будь-який тип закупівлі, зокрема «Самостійна закупівля»

### Requirement: Дозволені типи заявок у профілі працівника
WHEN адміністратор відкриває профіль працівника, the system SHALL показувати серед дозволених йому типів заявок «Витрата
карткою», «Запит на чек» і «Рахунок постачальника» лише ті, на які працівнику без ролі `admin` видано дозвіл, а для
адміністратора — усі ці типи.

#### Scenario: AC-ORG-17 З дозволом «Витрата карткою» вона серед дозволених типів
- **GIVEN** працівник без ролі `admin`, якому адміністратор видав дозвіл на «Витрату карткою»
- **WHEN** адміністратор відкриває профіль цього працівника
- **THEN** серед дозволених йому типів заявок є «Витрата карткою»

#### Scenario: AC-ORG-25 Адміністратор без дозволу має «Витрату карткою» серед дозволених
- **GIVEN** адміністратор без дозволу на «Витрату карткою»
- **WHEN** адміністратор відкриває його профіль
- **THEN** серед дозволених йому типів заявок є «Витрата карткою»

#### Scenario: AC-ORG-26 Без дозволу «Витрати карткою» серед дозволених немає
- **GIVEN** працівник без ролі `admin` і без дозволу на «Витрату карткою»
- **WHEN** адміністратор відкриває профіль цього працівника
- **THEN** серед дозволених йому типів заявок «Витрати карткою» немає

### Requirement: Дозволені типи закупівлі в профілі працівника
WHERE працівник без ролі `admin` не має дозволу «Самостійна закупівля», the system SHALL показувати в його профілі серед
дозволених типів закупівлі лише «Відділ закупівель».

#### Scenario: AC-ORG-27 Без дозволу серед дозволених типів закупівлі лише «Відділ закупівель»
- **GIVEN** працівник без ролі `admin` і без дозволу «Самостійна закупівля»
- **WHEN** адміністратор відкриває профіль цього працівника
- **THEN** серед дозволених йому типів закупівлі є лише «Відділ закупівель»
