# approver-decision-scope Specification

## Purpose
Визначає, що схвалювач бачить у списку для рішення й по яких заявках може вирішувати: лише по поданих заявках свого
відділу, крім власних; чужий відділ, заявник без права рішення, власна заявка й рішення без причини відхилення
отримують відмову, і заявка не змінюється.

## Requirements

### Requirement: Список для рішення схвалювача
WHEN схвалювач відкриває свій список для рішення, the system SHALL показувати в ньому подані заявки лише відділів, які
він схвалює, крім заявок, автором яких він є.

#### Scenario: AC-APR-01 У списку для рішення лише заявки свого відділу
- **GIVEN** очікують схвалення дві заявки відділу «Початкова школа» й одна заявка відділу «Офіс», схвалювач Марія схвалює лише «Початкова школа»
- **WHEN** Марія відкриває свій список для рішення
- **THEN** вона бачить дві заявки відділу «Початкова школа»
- **AND** заявки відділу «Офіс» у списку немає

### Requirement: Схвалення заявки свого відділу
WHEN схвалювач схвалює заявку відділу, який він схвалює і де він не автор заявки, the system SHALL встановити заявці
статус «Схвалено».

#### Scenario: AC-APR-02 Схвалення заявки свого відділу
- **GIVEN** заявка відділу «Початкова школа» зі статусом «Очікує схвалення», автор — не Марія, Марія схвалює цей відділ
- **WHEN** Марія схвалює її
- **THEN** статус заявки «Схвалено»

### Requirement: Заявка чужого відділу за прямим посиланням
WHEN схвалювач відкриває за прямим посиланням заявку відділу, який він не схвалює, the system SHALL показати повідомлення
«Недостатньо прав», не показувати даних заявки й не змінювати її статус.

#### Scenario: AC-APR-03 Заявка чужого відділу недоступна схвалювачу
- **GIVEN** заявка відділу «Офіс» зі статусом «Очікує схвалення», Марія схвалює лише «Початкова школа»
- **WHEN** Марія відкриває цю заявку за прямим посиланням
- **THEN** вона бачить повідомлення «Недостатньо прав»
- **AND** даних заявки їй не показано
- **AND** статус заявки лишається «Очікує схвалення»

### Requirement: Список для рішення для заявника
WHEN працівник з роллю `requester` відкриває список для рішення за прямим посиланням, the system SHALL показати
повідомлення «Недостатньо прав», не показувати жодної заявки й не змінювати статуси заявок.

#### Scenario: AC-APR-04 Заявник не бачить списку для рішення
- **GIVEN** працівник 1 з роллю `requester` увійшов
- **WHEN** він відкриває список для рішення за прямим посиланням
- **THEN** він бачить повідомлення «Недостатньо прав»
- **AND** жодної заявки йому не показано
- **AND** статуси заявок не змінилися

### Requirement: Схвалення власної заявки напряму
IF схвалювач, який є автором заявки, намагається схвалити її напряму, оминаючи сторінки застосунку, THEN the system SHALL
лишити статус заявки без змін.

#### Scenario: AC-APR-05 Схвалювач не схвалює власної заявки
- **GIVEN** Петро — схвалювач відділу «Початкова школа» і автор заявки зі статусом «Очікує схвалення»
- **WHEN** він намагається схвалити свою заявку напряму, оминаючи сторінки застосунку
- **THEN** статус заявки лишається «Очікує схвалення»

### Requirement: Відхилення без причини
IF схвалювач відхиляє заявку, не вказавши причину, THEN the system SHALL показати повідомлення «Вкажіть причину» і
лишити статус заявки «Очікує схвалення».

#### Scenario: AC-APR-06 Відхилення без причини не приймається
- **GIVEN** схвалювач Марія відхиляє заявку відділу «Початкова школа», не вказавши причину
- **WHEN** вона підтверджує
- **THEN** вона бачить повідомлення «Вкажіть причину»
- **AND** статус заявки лишається «Очікує схвалення»

### Requirement: Відхилення заявки з причиною
WHEN схвалювач відхиляє заявку відділу, який він схвалює і де він не є автором заявки, вказавши причину, the system SHALL встановити заявці статус
«Відхилено», зберегти причину й показати її на сторінці заявки поруч зі статусом.

#### Scenario: AC-APR-07 Відхилення з причиною
- **GIVEN** заявка відділу «Початкова школа» зі статусом «Очікує схвалення», автор — не Марія, Марія схвалює цей відділ
- **WHEN** Марія відхиляє її, вказавши причину «Немає бюджету»
- **THEN** статус заявки «Відхилено»
- **AND** причину «Немає бюджету» збережено й показано на сторінці заявки поруч зі статусом «Відхилено»
