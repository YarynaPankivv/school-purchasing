# 0006. AI-помічник зрізу 4: AI SDK + OpenRouter (безкоштовні моделі) + zod, тексти українською

- Статус: прийнято
- Дата: 2026-11-14
- AC: AC-AI-01, AC-AI-02, AC-AI-03, AC-AI-04, AC-AI-05, AC-AI-06

## Контекст

Зріз 4 (WS10, ValiaBihun/2026-quitcode-dream-team#71) додає «Запропонувати рядки»: вільний опис покупки → один рядок
закупівлі (назва, мета, кількість, ціна), який працівник перевіряє й сам зберігає чи подає. Обмеження:

- Next.js 16.4 на Vercel Hobby; Server Action — до 1 МБ за замовчуванням, функція — до 300 с, а AC-AI-04 дає 15 секунд.
- Модель — безкоштовна через OpenRouter, ключ власний. Ліміт безкоштовних моделей — 20 запитів/хв і 50/день на акаунт
  (його ділить усе, що користується застосунком: eval, UAT, golden cases PM); додаткові ключі ліміту не збільшують.
  Безкоштовні моделі з'являються й зникають.
- Безкоштовні ендпоінти можуть зберігати запити й навчатися на них → лише синтетичні дані.
- Відповідь моделі недетермінована, а CI має бути без мережі й без секретів.
- Вимога PM вимагає українських текстів помічника (AC-AI-02 «Я допомагаю лише із закупівлями» тощо), а решта інтерфейсу —
  англійська (AC-LANG-01, `requirements/49-…`); питання до PM — ValiaBihun/2026-quitcode-dream-team#77.

## Рішення

- Нові залежності (точні версії; набір курсу `materials/ai-feature`): `ai@7.0.162`, `@openrouter/ai-sdk-provider@3.1.0`,
  `zod@4.6.7`, `server-only@0.0.1`.
- Виклик — `generateText` + `Output.object({ schema })` (`src/lib/ai/draft.ts`, чиста функція `proposeDraft(input, model)`).
  Схема zod (`src/lib/ai/schema.ts`): `status: ok | needs_info | refused`, `refusal: not_purchase | instruction | null`,
  поля рядка, «невідоме» = `null`. Межі «ціле від 1» і «ціна від 0» перевіряє код (`parseLineFields`), а не лише промпт.
- Ключ `OPENROUTER_API_KEY` читає лише `src/lib/ai/openrouter.ts` з `import "server-only"` (його перевіряє `tests/ai-key.test.ts`),
  без `NEXT_PUBLIC_`; у Vercel — Production і Preview, у `.env.local` — локально. Немає ключа → `productModel()` дає `null`,
  помічник «недоступний» (AC-AI-04), ручна форма працює далі.
- Ланцюжок моделей (лише `:free`): `google/gemma-4-31b-it:free` → `google/gemma-4-26b-a4b-it:free` →
  `nvidia/nemotron-3.5-super-vl:free` (`src/lib/ai/models.ts`); `maxRetries: 0`, таймаут 14 с на сервері й 15 с на клієнті (AC-AI-04).
- Людина в контурі: Server Action `suggestLine` лише повертає пропозицію (нічого не пише), запис — звичайні «Save» / «Submit» і
  `addLineWithValues` (лише коли в формі немає порожнього рядка) після повторної перевірки zod + `parseLineFields` під сесією
  користувача (RLS). Обидві дії спершу перевіряють `getClaims()` і право автора редагувати рядки — до виклику моделі.
- Промпт — окремий модуль з версією `DRAFT_PROMPT_VERSION`; опис покупки йде між тегами `<document>`, теги з вводу вирізано,
  довжину обмежено (1000 символів).
- Тексти помічника — **українські, дослівно з AC PM**, у єдиному модулі `src/lib/ai/messages.ts`, який сканер AC-LANG-01
  (`tests/ui/interface-language.test.ts`) явно пропускає. Якщо PM відповість «англійською» (#77) — змінюємо цей файл.
- Перевірка якості: 10 golden cases PM (`tests/fixtures/golden/cases.json`). Офлайн-реплей записаних відповідей
  (`MockLanguageModelV4`) у `npm test` (CI); живий прогін — `npm run eval` вручну, звіт у `evals/reports/`.

## Розглянуті варіанти

- Claude Agent SDK у функції Vercel — ні: підпроцес Claude Code (~320–342 МБ) не вміщується в пакет функції, а потрібен один виклик моделі.
- Власний `fetch` до OpenRouter без SDK (перша версія цього зрізу) — ні: немає типізованих помилок, валідації схемою й
  тестових моделей (`MockLanguageModelV4`) в одному API; вимога курсу — zod і `server-only`.
- `openrouter/free` (випадкова безкоштовна модель) — ні: результат golden cases не відтворюється.
- Платний ключ — ні: курс використовує безкоштовні моделі; перехід — заміна однієї фабрики в `models.ts`.
- Українські тексти помічника в окремому модулі vs. англійські переклади — поки українські за AC PM, питання PM #77.

## Наслідки

- Простіше: провайдера й модель міняємо в одному файлі; CI не залежить від мережі та ліміту; клієнтський код ключа не бачить.
- Складніше: безкоштовна модель може зникнути чи впертися в ліміт — інтерфейс показує повідомлення AC, а форма працює вручну;
  ланцюжок перевіряємо `npm run ai:models` перед роботою.
- Записи `tests/fixtures/golden/recorded.json` треба оновлювати (`RECORD=1 npm run eval`), коли змінюється промпт
  (`DRAFT_PROMPT_VERSION`) або схема.
- Мова: поки PM не відповіла на #77, один файл (`messages.ts`) має українську; рішення може змінитися без зміни логіки.
